# Virtual Operating System

## Description
A Virtual Operating System project developed as part of academic coursework to simulate core operating system functionalities and enhance problem-solving skills.

## Features
- Simulates core operating system functionalities
- Demonstrates key operating system concepts
- User-friendly interface
- Academic learning project

## Technologies Used
- Python
- Django
- SQLite

## Installation
1. Clone the repository:
   git clone https://github.com/mohitdhande16-dev/operating-system-project.git

2. Install the required dependencies:
   pip install -r requirements.txt

3. Run the development server:
   python manage.py runserver

4. Open the application in your browser.
